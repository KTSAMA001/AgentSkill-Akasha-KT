### 概要

从图形学实际使用出发，解释标量、向量、矩阵、点积、叉积、矩阵乘法、转置、单位矩阵和逆矩阵。重点解决“点积为什么可以写成转置后的矩阵乘法”“不同乘法如何展开”“矩阵运算顺序为什么不能随意交换”等入门问题，并给出与 HLSL `mul` 的对应关系。

### 内容

#### 一、阅读约定

本文主要使用列向量：

```text
v = [ x, y, z ]^T
```

右上角 `T` 表示 transpose（转置），不是变量名。常用符号如下：

| 符号 | 含义 |
|------|------|
| `a`、`b`、`v` | 向量 |
| `A`、`B`、`M` | 矩阵 |
| `A^T` | `A` 的转置 |
| `A^-1` | `A` 的逆矩阵 |
| `A^-T` | `A` 的逆转置，等于 `(A^-1)^T` |
| `I` | 单位矩阵 |
| `a'` | 变换后的向量；`'` 与转置符号 `T` 无关 |

#### 二、标量、向量与矩阵

##### 2.1 标量

标量是单个数字，例如亮度 `0.8`、距离 `5`、统一缩放 `2`。标量只有大小，没有空间方向。

##### 2.2 向量

向量是一组有顺序的数字。在图形学中，三维向量经常表示位置、方向、速度、颜色或法线：

```text
v = [ x, y, z ]^T
```

虽然它们都可能使用 `float3` 存储，但语义不同：

- 位置表示“在哪里”。
- 普通方向表示“朝哪里”。
- 法线表示“哪个方向与表面切平面垂直”，变换规则与普通方向不同。

##### 2.3 矩阵

矩阵是按行列排列的数字，可以表达旋转、缩放、剪切和坐标空间转换。

```text
M = [ 2  0 ]
    [ 0  1 ]
```

这个二维矩阵把 X 放大两倍，Y 保持不变。若 `v` 是列向量，则：

```text
v' = Mv
```

表示矩阵 `M` 对向量 `v` 执行一次线性变换。

#### 三、向量的基础运算

##### 3.1 向量加减

向量加减按对应分量计算：

```text
[ ax ]   [ bx ]   [ ax+bx ]
[ ay ] + [ by ] = [ ay+by ]
```

位置 `B - A` 可以得到从 A 指向 B 的方向与距离信息。

##### 3.2 长度与归一化

二维向量 `v = [x, y]^T` 的长度为：

```text
|v| = sqrt(x*x + y*y)
```

归一化会保留方向、把长度变成 1：

```text
normalize(v) = v / |v|
```

零向量没有方向，不能直接除以长度归一化；代码中需要使用安全归一化或提前判断。

##### 3.3 点积：得到一个标量

两个向量的点积为：

```text
a · b = ax*bx + ay*by + az*bz
```

它也满足：

```text
a · b = |a||b|cos(theta)
```

常见用途：

- `a · b > 0`：夹角小于 90 度，大致同向。
- `a · b = 0`：互相垂直。
- `a · b < 0`：夹角大于 90 度，大致反向。
- 两个向量都归一化后，点积直接等于夹角余弦。

当 `a`、`b` 都写成列向量时，点积可以改写成矩阵乘法：

```text
a · b = a^T b
```

这里左边的 `·` 是向量点积符号，右边的相邻书写是矩阵乘法。因为 `a^T` 是 `1×n` 行向量，`b` 是 `n×1` 列向量，矩阵乘法只产生一个元素：

```text
a^T b = [ ax  ay  az ] [ bx ] = ax*bx + ay*by + az*bz
                         [ by ]
                         [ bz ]
```

因此右边在运算形式上是矩阵乘法，但在这个特定尺寸下，结果正好等于点积。

##### 3.4 外积：得到一个矩阵

交换行列方向后：

```text
ab^T
```

是 `n×1` 乘 `1×n`，结果为 `n×n` 矩阵，称为外积。相邻书写不一定表示点积，必须先检查尺寸。

##### 3.5 叉积：得到垂直方向

三维叉积 `a × b` 的结果是一个同时垂直于 `a`、`b` 的向量：

```text
a × b = [ ay*bz - az*by,
          az*bx - ax*bz,
          ax*by - ay*bx ]^T
```

交换顺序会反向：

```text
a × b = -(b × a)
```

图形学中常用叉积从切线和法线构造副切线，或从两个三角形边向量计算面法线。坐标系左右手性和负缩放会影响最终方向，不能只看数值公式。

#### 四、矩阵有哪些常见计算方式

##### 4.1 加减法

矩阵尺寸必须相同，对应元素相加减：

```text
[ a  b ] + [ e  f ] = [ a+e  b+f ]
[ c  d ]   [ g  h ]   [ c+g  d+h ]
```

##### 4.2 标量乘矩阵

每个元素都乘同一个标量：

```text
k [ a  b ] = [ ka  kb ]
  [ c  d ]   [ kc  kd ]
```

##### 4.3 Hadamard 积：对应元素相乘

Hadamard 积通常写作 `A ⊙ B`，要求矩阵尺寸相同：

```text
[ a  b ] ⊙ [ e  f ] = [ ae  bf ]
[ c  d ]   [ g  h ]   [ cg  dh ]
```

它不是线性代数中的矩阵乘法。

##### 4.4 矩阵乘法：行乘列

尺寸规则：

```text
(m×n)(n×p) = (m×p)
```

中间两个尺寸必须相同，结果保留外侧尺寸。若 `C = AB`，`C` 的第 `i` 行、第 `j` 列元素，是 `A` 的第 `i` 行与 `B` 的第 `j` 列做点积。

```text
A = [ a  b ]    B = [ e  f ]
    [ c  d ]        [ g  h ]

AB = [ ae+bg  af+bh ]
     [ ce+dg  cf+dh ]
```

矩阵乘向量是矩阵乘法的特殊情况：

```text
[ a  b ] [ x ] = [ ax+by ]
[ c  d ] [ y ]   [ cx+dy ]
```

##### 4.5 常见乘法对照

| 写法 | 名称 | 核心规则 | 结果 |
|------|------|----------|------|
| `ka` | 标量乘向量 | 每个分量乘 `k` | 向量 |
| `kA` | 标量乘矩阵 | 每个元素乘 `k` | 矩阵 |
| `A ⊙ B` | Hadamard 积 | 对应元素相乘 | 矩阵 |
| `AB` | 矩阵乘法 | 行乘列 | 矩阵或向量 |
| `a · b` / `a^T b` | 点积 | 分量乘积求和 | 标量 |
| `ab^T` | 外积 | 列向量乘行向量 | 矩阵 |
| `a × b` | 三维叉积 | 右手/左手规则决定方向 | 向量 |

#### 五、转置、单位矩阵与逆矩阵

##### 5.1 转置

转置会交换矩阵的行和列：

```text
A   = [ a  b ]    A^T = [ a  c ]
      [ c  d ]          [ b  d ]
```

乘积转置时顺序反转：

```text
(AB)^T = B^T A^T
```

可以把它理解为：如果组合变换先做 `B`、再做 `A`，转置后的对应操作必须反向拆开。

##### 5.2 单位矩阵

单位矩阵在矩阵运算中类似数字 `1`：

```text
I = [ 1  0 ]
    [ 0  1 ]

Iv = v
AI = IA = A
```

##### 5.3 逆矩阵

逆矩阵用于撤销一个可逆变换：

```text
A^-1 A = A A^-1 = I
```

例如一个轴缩放两倍，逆变换就在该轴缩放为二分之一。某个缩放轴为零时，空间被压扁，丢失的信息无法恢复，因此矩阵不可逆。

##### 5.4 逆转置

逆转置的等价写法：

```text
A^-T = (A^-1)^T = (A^T)^-1
```

所以：

```text
A^T A^-T = I
```

但一般不能写成：

```text
A A^-T = I
```

逆转置在法线变换中用于保持法线与变换后切平面的垂直关系，完整推导见相关记录。

#### 六、必须记住的矩阵规则

```text
(AB)C = A(BC)          结合律：可以改变括号
A(B+C) = AB+AC         分配律
AB != BA               通常不满足交换律
(AB)^T = B^T A^T       转置会反转顺序
(AB)^-1 = B^-1 A^-1    求逆也会反转顺序
```

“反转顺序”可以这样理解：穿鞋再系鞋带，撤销时必须先解鞋带再脱鞋；组合变换的逆也遵循相反顺序。

#### 七、点、方向与齐次坐标

三维图形常用 4×4 矩阵同时表达旋转、缩放和平移。此时会给三维量增加一个 `w`：

```text
位置：    [ x, y, z, 1 ]^T
普通方向：[ x, y, z, 0 ]^T
```

位置的 `w = 1`，因此会受到平移影响；方向的 `w = 0`，平移项乘零，不会改变方向。法线通常也不受平移影响，但遇到非均匀缩放或剪切时，还需要逆转置，不能仅按普通方向处理。

#### 八、数学写法与 HLSL `mul`

数学推导常用列向量：

```text
v' = Mv
```

HLSL 使用 `mul(x, y)` 表达矩阵乘法：

```hlsl
mul(M, v) // v 被视为列向量，计算 Mv
mul(v, M) // v 被视为行向量，计算 vM
```

向量放在左边还是右边会改变数学含义，不能只根据代码看起来是否“能编译”判断正确性。

矩阵按 row-major 或 column-major 存储，描述的是数据打包和读取布局；`mul` 的操作数顺序描述的是数学乘法方向。这两个概念相关但不相同。

在 Unity Shader 中，优先使用 `TransformObjectToWorld`、`TransformObjectToWorldDir`、`TransformObjectToWorldNormal` 等库函数，避免重复处理平台差异和非均匀缩放分支。

#### 九、图形学入门记忆卡

```text
点积：        a · b，结果是标量；等于零表示垂直
叉积：        a × b，结果是垂直于二者的向量
矩阵乘法：    行乘列，中间尺寸相同
矩阵顺序：    AB 通常不等于 BA
转置：        交换行列，(AB)^T = B^T A^T
逆矩阵：      撤销变换，A^-1 A = I
逆转置：      A^-T = (A^T)^-1
位置与方向：  w=1 受平移影响，w=0 不受平移影响
```
