## 1. 读者复述

本文面向 Unity 2022.3 中“数千个飞虫实例从环绕状态聚合成多个预制网格轮廓，并能连续换形”的 MVP。适用前提是实例容量固定、虫子共用单一 Mesh 与材质、目标形状可预先烘焙；它不是生产平台性能、真实昆虫美术、VFX Graph 或 BRG 路线的认证。

端到端机制可以复述为：

1. Editor 阶段在目标 Mesh 的局部空间内，按三角形面积加权进行均匀表面采样；拒绝空、全退化或包含非有限值的输入。
2. 使用固定 Seed 保证结果可重复，再将各形状的点分别做 Morton 排序，得到数量完全一致的 `ShapeAsset`。这种对应关系成本低且通常能减少远距离交叉，但不保证全局最短路径。
3. 运行时一次性分配持久 `Agent Buffer`、Active/Incoming 双目标 Buffer 和 Indirect Args Buffer。稳定实例 ID 同时关联 Agent、目标点和 VAT 相位。
4. ComputeShader 根据状态机生成 Orbit、Shape、Retarget 或 Disperse 目标，并用带阻尼的弹簧模型持续积分位置和速度；通过限制 `deltaTime`、加速度和速度降低卡顿后的数值爆炸风险。
5. 换形时只上传 Incoming 点云，在两个目标之间平滑插值，结束后交换 Buffer 引用；不覆盖当前位置、不清空速度，也不重建 Agent，因此实例身份、速度和动画相位保持连续。
6. C# 使用 `Graphics.DrawMeshInstancedIndirect` 提交固定容量实例。顶点着色器通过 `SV_InstanceID` 读取 Agent 状态，通过 `SV_VertexID` 和每实例相位读取位置 VAT，从而让同一虫子网格呈现错相动画。
7. 屏幕上的可观察闭环是 `Orbit → Assemble → HoldShape → Retarget → HoldShape → Disperse → Orbit`，并用测试、状态诊断、多视角截图及换形中间帧分别验证数据不变量、生命周期和视觉结果。

文章清楚区分了表面点云和体积点云，也说明球体正弦 VAT 只验证数据通路，不代表正式昆虫资产已经解决。当前证据限定在 Unity 2022.3.62f3、URP 14.0.12、Apple M5/Metal 的真实 Editor 场景；Standalone、其他平台、生产级 VAT、剔除、LOD、碰撞和导航均需另行验证。
