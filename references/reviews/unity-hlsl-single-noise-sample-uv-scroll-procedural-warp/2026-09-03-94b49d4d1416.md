# 1. 读者复述

- 阅读前 SHA-256：`94B49D4D1416530D175C39B45782B07F3978133064A884703309F449445E239E`

本文适用于 Unity 2022.3 LTS、URP 14.0.12 中需要风格化方向流动、但希望限制噪声纹理采样次数的 Shader 场景。它解决的真实问题是：单纯平移 UV 只能让纹理整体滑动，轮廓和局部采样密度不变，容易呈现“贴纸滑过”的观感；而完整 FlowMap 方案又可能引入方向纹理、多相采样和相位混合等额外成本。

核心方案是将刚性滚动与程序化 Warp 分开控制。第二套 UV 先应用 Tiling/Offset；`scrollVector` 以 UV/秒表示整体滚动速度，`frac(time * scrollVector)` 在 Repeat 纹理语义下将偏移限制到一个周期。`warpVector` 的方向用于建立 Warp 轴，其长度作为周期/秒的时间相位速率。原始 `noiseUV` 分别投影到 Warp 轴和垂直轴，得到纵向与横向坐标；主相位 `Fs-wt` 形成沿正 Warp 方向传播的正弦波，两组具有不同空间系数、时间速度和运动符号的交叉正弦相位，再调制主波的相位与强度，使规则条带变得连续但不完全整齐。

最终标量位移沿 Warp 轴加到采样坐标上，与基础滚动共同形成 `sampleUV`。Shader 使用该坐标读取一次灰度 Noise，再读取一次 Ramp，将结果经 Tint 和 Mask 合成到自发光区域。因此“单次采样”限定为 Noise 只采样一次，而不是整个 Flow 颜色链只有一次纹理读取。

各参数的职责和单位可以独立复述：滚动向量为 UV/秒；Warp 向量长度为周期/秒；频率为周期/UV；强度为 UV 位移；不规则度无量纲；不规则密度近似为周期/UV。Scroll 是整个采样域的刚性平移，Warp 则通过位置相关位移改变局部采样密度。主波传播速度为 `warpSpeed / warpFrequency`，频率为零时只剩全域同步变化，不能再解释为空间行进波。

主要失败方式也交代清楚：滚动偏移的等价回绕依赖 Repeat，Clamp 不适用；不无缝纹理仍会暴露接缝；全局时间长期增长仍会损失浮点精度；Point 过滤可能造成离散跳变；规则主波在 `2π|AF|` 接近或超过 1 时可能发生 UV 局部反转和折叠，而加入不规则调制后该条件只能作为基础风险估算；本方法不提供真实速度场、质量守恒、旋涡或物理流体行为。
